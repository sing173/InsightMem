# 常见误区

> 配套：[八周路线](README.md)

---

1. **把上下文窗口当记忆**：窗口是工作台，不是档案库。
2. **把 compaction 当长期记忆**：压缩是为了继续当前会话，不是为了跨会话。
3. **认为记得越多越好**：[Anthropic 的 Pokémon 案例](https://www.anthropic.com/research/components-of-agent-memory)里，413 个文件的记忆只拿到 1 枚徽章，9 个文件的拿到 4 枚。
4. **只做向量检索**：代码、错误码、路径、罕见标识符会漏。
5. **写入即摘要**：摘要丢掉的约束，后面无法审计。
6. **只追加不处理矛盾**：旧事实会和新事实平等竞争。
7. **没有用户/租户隔离**：一次查询越界就是事故。
8. **用厂商自报分数选型**：口径不同，不可直接比。
9. **评测不固定 answerer/prompt**：你测到的是模型差异，不是记忆差异。
10. **忽略 token 和延迟**：记忆系统的成本常在读取侧。
11. **没有删除路径**：隐私和合规要求“可删、可审计”。
12. **把图当万能**：抽取质量差时，图只是更贵的噪声。

## 自查

- 你的系统里，哪一层是“原始事实”，哪一层是“提炼”？
- 旧事实被新事实取代时，查询会返回哪一个？
- 用户要求删除时，你能删干净吗？
- 你的评测里，answerer 和 top_k 固定了吗？
- 如果去掉一条召回腿，分数会掉多少？
