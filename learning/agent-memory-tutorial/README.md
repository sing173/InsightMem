# Agent 记忆系统学习路线（2026）

> 面向：有 Python 基础、用过 LLM API、想系统掌握 agent memory 的开发者。
> 时长：8 周主线（通常每周 6–8 小时，Capstone 10–14 小时），或 4 周速通；12 周可加读论文。
> 最终产出：一个可评测的 mini memory service + 一份架构/实验报告。
> 配套代码：InsightMem（本仓库）作为参考实现；L2–L5 可直接使用，L6 的治理能力需自行扩展。
> 版本：2026-11-24。所有分数都标口径，不同 benchmark 的数字不要横比。

本目录按周章节组织；每章是主学习文件，实验、评测与资源手册提供可执行细节和一手出处。章节中的项目现状均指当前 InsightMem 实现，不代表其他框架或未来版本。

## 每周节奏

每周固定四件事：

- **读**：1 篇一手文档 + 1 篇论文（只精读方法/实验，不逐字读）；
- **画**：把该系统的写入/读取/更新路径画成一页图；
- **做**：跑一个对照实验，必须有 baseline；
- **写**：一页结论，包含数字、口径、失败案例。

不要收集“教程合集”当学习。每读一个资源，必须产出一个能复述的结论或一个实验。

## 约定

- 一手文档 > 论文 > 二手解读 > 短视频；二手材料只用来建立直觉，不引用其数字。
- 看到“某系统提升 X%”先问：baseline 是什么、answerer 是谁、数据集多大、是不是厂商自报。
- 每读一个框架，画一张“写入/读取/更新”三列图，比读十篇测评更有用。
