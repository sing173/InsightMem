## A Survey on the Memory Mechanism of Large Language Model based Agents（2024）

**作者**：Zeyu Zhang, Xiaohe Bo, Chen Ma, Rui Li, Xu Chen, Quanyu Dai, Jieming Zhu, Zhenhua Dong, Ji-Rong Wen
**时间**：2024（arXiv:2404.13501v1，CC BY）
**一句话**：最早系统梳理“LLM agent 记忆”的综述之一，回答“是什么、为什么、怎么设计、怎么评估”。

### 摘要（译文）

基于 LLM 的 agent 因自演化能力而受到研究和产业关注；支持 agent 与环境长期复杂交互的关键组件是记忆。已有研究提出了许多有前景的记忆机制，但分散在不同论文中，缺乏从整体视角总结和比较的系统综述，无法抽象出共同、有效的设计模式。为填补这一空白，本文对 LLM agent 的记忆机制做了全面综述：首先讨论 LLM agent 中“什么是记忆”和“为什么需要记忆”；然后系统回顾如何设计和评估记忆模块；接着介绍记忆模块发挥重要作用的应用；最后分析现有工作的局限并给出重要未来方向。作者维护了一个持续更新的仓库。

### 内容地图

- **是什么 / 为什么**：记忆的定义、作用、与上下文窗口的区别；
- **怎么设计**：记忆的来源、形式、写入/读取/更新操作；
- **怎么评估**：数据集、指标、实验设计；
- **应用**：对话、推荐、游戏、个人助手等；
- **局限与方向**：长程一致性、动态更新、评估缺失等。

### 怎么读

- 用来补术语和早期工作，不要把它当 2026 年的最新地图；
- 重点看“设计维度”和“评估维度”两章，建立自己的分类表；
- 读到具体系统时，回到原始论文核对，不要只引用综述的二手描述。

### 局限

- 截止 2024 年，未覆盖 2025–2026 的图记忆、时序记忆、编码记忆等进展；
- 分类框架是作者视角，不同论文的术语并不统一；
- 综述中的比较通常是定性的，不是同 benchmark 的定量对比。

## From Storage to Experience: A Survey on the Evolution of LLM Agent Memory Mechanisms（2026）

**作者**：Jinghao Luo, Yuchen Tian, Chuxue Cao, Ziyang Luo, Hongzhan Lin, Kaixin Li, Chuyi Kong, Ruichao Yang, Jing Ma
**时间**：2026（arXiv:2605.06716v1）
**一句话**：把记忆机制演化分成“存储 → 反思 → 经验”三阶段，并指出主动探索与跨轨迹抽象两个前沿。

### 摘要（译文）

基于 LLM 的 agent 通过整合外部工具和规划能力重塑了 AI。记忆机制已成为这些系统的架构基石，但当前研究在操作系统工程和认知科学之间摇摆，呈碎片化状态；这种理论分歧阻碍了统一的技术综合和连贯的演化视角。为弥合差距，本文提出一个新的演化框架，把 LLM agent 记忆机制的发展形式化为三个阶段：**存储（Storage，轨迹保存）→ 反思（Reflection，轨迹提炼）→ 经验（Experience，轨迹抽象）**。作者先形式化定义这三个阶段，再分析演化的三个核心驱动：长程一致性的需求、动态环境的挑战、持续学习的终极目标。文章还专门探讨经验阶段的两个变革性机制：**主动探索（proactive exploration）**和**跨轨迹抽象（cross-trajectory abstraction）**。通过综合这些分散视角，本文为下一代 LLM agent 提供设计原则和路线图。

### 三阶段框架

| 阶段 | 做什么 | 典型问题 |
|---|---|---|
| 存储 | 保存原始轨迹、消息、事件 | 怎么存、存多久、怎么检索 |
| 反思 | 从轨迹中提炼结论、规则、教训 | 怎么保证提炼不丢关键约束 |
| 经验 | 跨轨迹抽象成可复用知识/技能 | 怎么验证、怎么迁移、怎么避免过时 |

### 三个驱动

- **长程一致性**：跨会话、跨任务保持事实和决策一致；
- **动态环境**：世界会变，记忆必须能失效和更新；
- **持续学习**：agent 要从自身经验中变强，而不只是检索。

### 怎么读

- 用三阶段框架给自己的系统定位：你停在存储、反思还是经验？
- 重点看“经验”阶段的两个机制，它们对应 2026 年最前沿的 agent 自演化方向；
- 注意这是 2026 年的综述，覆盖面比 2024 综述新，但仍不是定量对比。

### 局限

- 论文页未显示开放许可，本目录只做导读；
- 三阶段是作者提出的演化叙事，不是唯一分类；
- “经验”阶段的工程落地仍不成熟，很多例子是研究原型。

## 三篇综述怎么配合读

1. **2024 综述**：补术语和早期系统，建立“设计/评估”两轴；
2. **2026 演化综述**：用“存储 → 反思 → 经验”看趋势，定位自己的系统；
3. **2026 数据驱动综述**：看研究分布和分类扩展，但先确认全文可得。

读综述的输出不是笔记，而是一张表：每篇论文落在哪个阶段、用什么记忆单元、怎么更新、怎么评估。把这张表填完，再进入 [03 现代系统](03-systems.md)。
